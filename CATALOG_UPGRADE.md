# 24XSTORE — PS4 / PS5 + PS Plus catalog

## Что добавлено
- отдельный каталог PS4 и PS5;
- импорт платных товаров с публичных страниц PlayStation Store Turkey;
- текущая/старая цена и процент скидки;
- отдельный раздел PS Plus: Essential / Extra / Deluxe;
- корзина принимает игры и подписки;
- итоговая цена = TRY × DEFAULT_TRY_RUB × (1 + DEFAULT_MARKUP).

## Важно про PS Plus
Если автоматическое обнаружение официальных страниц подписок временно не сработает, неизвестные цены показываются как «Цена уточняется» и товар нельзя добавить в корзину. Essential 1 месяц имеет резерв 400 TL по публичной странице PlayStation Store; остальные резервные цены можно задать переменными окружения PSPLUS_*.

## Защищённая синхронизация
Задайте ADMIN_SYNC_TOKEN в окружении контейнера. Затем:

POST /api/catalog-sync?max_pages=4
Header: X-Admin-Token: <ваш токен>

Для первого теста 4 страницы на PS4 и 4 на PS5 достаточно. Позже можно увеличить max_pages.

## Важное ограничение
PlayStation Store не предоставляет документированный публичный storefront API для этого сценария. Импорт использует публичные страницы магазина и может потребовать адаптации, если Sony изменит HTML/внутренние запросы.
